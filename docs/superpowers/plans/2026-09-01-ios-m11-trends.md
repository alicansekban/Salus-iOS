> yerine sözleşme + davranış listesi verilir. Implementer tam kodu kendisi yazar, testleri

**Goal:** Android'in "Plan 3 — Gelişmiş Trendler" planının iOS portunu yapmak: premium-gated trends ekranı, dört analiz kartı (sabah-akşam dağılımı, çoklu metrik overlay, doz-ölçüm ilişkisi, istatistik özeti), kilitli önizleme (örnek veri + blur), ve paywall feature list hizalaması.

**Architecture:** Yeni `FeatureTrends` paketi (boş placeholder mevcut) doldurulur: domain modelleri, `TrendsReader`/`TrendsRepository` (premium gate), dört saf analiz modülü, ViewModel/Screen. `SalusUI` iki yeni grafik bileşeni kazanır (`SalusBarChart`, `SalusMultiSeriesChart`). `MetricStats`/`Trend` zaten `SalusModel`'da (Android Task 1 gerekmez). Features Charts'a direkt erişemez — `SalusUI` adapter'ları üzerinden.

**Tech Stack:** Swift Charts (sistem framework, `SalusUI` içinde, `#if canImport(Charts)`), SwiftUI, Swift 6, `@Observable`, GRDB (mevcut DAO'lar), `PremiumRepository`/`PaywallController` (M9'dan).

**Spec:** `salus-ios/docs/superpowers/specs/2026-09-01-ios-m11-trends-design.md` (approved)

## Global Constraints

- Mevcut hiçbir ücretsiz özellik kısıtlanmaz. `FeatureVitals`'ın `ChartRange` çipleri ücretsiz kalır; `ChartRange` enum'una ve Vitals grafiğine dokunulmaz. Trends kendi `TrendsRange` enum'unu taşır.
- "Uyum" / "adherence" / "planlanan doz" / "hedef aralık" ifadeleri yasak. `MISSED` satırı hiç yazılmadığı için oranın paydası kaydedilen dozdur. UI metni yalnız "kaydedilen doz" semantiğiyle konuşur. Repo-wide `BannedHealthClaims` scan yeni string'leri otomatik tarar.
- Hedef aralık / normal değer iddiası yasak. Hiçbir kart bir değeri iyi/kötü/normal diye nitelemez; yalnız sayı, ortalama ve değişim gösterilir.
- Premium kontrolü repository katmanındadır. Free kullanıcı için repository hiçbir DAO'ya dokunmaz. Ekran girişi serbesttir — free kullanıcı ekrana gider, kilidi görür.
- Ağ yok. Tüm hesap lokaldir.
- `MetricStats`/`Trend`/`metricStatsOf`/`trendOf` zaten `SalusModel`'da — taşıma gerekmez.
- Features asla Charts import etmez — grafikler yalnız `SalusUI` modelleri üzerinden. `no_charts_in_features` lint rule bunu zorlar.
- Cross-feature navigasyon shell callback'i ile. `TrendsKey` yalnız `FeatureTrends` içinde yaşar.
- `SalusClock` enjekte edilir. `domain/` paketinde UI framework importu yasak.
- Her kullanıcıya görünen string: `Localizable.xcstrings` (TR source + EN). Placeholder mapping: `%1$s`→`%1$@`, `%1$d`→`%1$lld`.
- Swift 6, `@MainActor @Observable` ViewModel'lar, `Sendable`, English comments.
- Yeni SPM dep YOK — Swift Charts sistem framework.
- `FeatureTrends` paketi **boş placeholder** olarak mevcut — `Package.swift` deps zaten tanımlı.
